# Simple To-Do List (In-Memory)

A simple responsive To-Do List created as **Task 16** of my
**Web Development Internship at Veda Technology**.

## Project Overview

This project is a basic in-memory to-do list where users can add
and remove tasks.

Tasks are stored in a JavaScript array and are not persisted after
the page is refreshed.

## Objective

The objective of this task was to practice:

- JavaScript arrays
- Array manipulation
- DOM rendering
- Event handling
- Event delegation
- Form handling
- Dynamic UI updates
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Add new tasks
- Display tasks from a JavaScript array
- Delete individual tasks
- Task count display
- Empty-state message
- Form validation for empty tasks
- Event delegation for delete buttons
- Responsive design
- In-memory storage only
